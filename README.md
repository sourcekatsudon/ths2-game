# THS // Power Split Lab

THS IIの動力分割機構を、走らせながら理解するGPU/WebGL教材です。2代目プリウス（NHW20）相当の公開仕様を基準に、遊星歯車、車両縦運動、モーター／発電機、バッテリーの電力収支をリアルタイム計算します。

画面右上から英語、日本語、中国語、ドイツ語、フランス語へ即時切り替えできます。選択言語はブラウザに保存されます。Energy Flowのパワーバーは、駆動出力をシステム最大82 kW、回生をバッテリー側上限25 kWに対する割合として表示します。

3Dリングギヤには回転を追いやすい非対称基準マーカーと周方向ストライプがあります。3D画面直下の3軸比較ローターは、Engine / MG1 / MG2を実回転の1/240で表示し、回転方向、実rpm、その瞬間の最速軸に対する回転比を示します。

## 起動

macOS / Linuxでは、ビルド・プレビューサーバー・ブラウザ起動をまとめて実行できます。

```bash
./run.sh
```

開発時は `npm run dev`、本番ビルドは `npm run build` です。

## 操作

- 画面のACCEL / BRAKEスライダー
- `W` / `↑`: アクセルを増やす
- `S` / `↓`: ブレーキを増やす
- `Space`: 一時停止 / 再開
- 3D画面をドラッグ: 視点回転、ホイール: ズーム

## モデル

遊星歯車の回転数は、リング78歯、サン30歯として次式で拘束しています。

```text
78 × n(MG2) + 30 × n(MG1) = 108 × n(Engine)
```

車速からタイヤ回転数と最終減速比4.113を介してMG2回転数を求め、エンジン運転点からMG1回転数を一意に算出します。車両運動には転がり抵抗、空気抵抗、勾配抵抗を含みます。

公開最大仕様は実値ですが、メーカー非公開のハイブリッド制御、過渡特性、詳細な効率マップは教育用近似です。実車ECUの再現や設計検証を目的とするモデルではありません。
